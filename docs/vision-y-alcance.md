# Vision y Alcance

## Vision del juego

`El Monstruo de la Laguna` debe ser un juego de plataformas submarino, legible y amable para infancias, donde el objetivo sea explorar niveles, evitar peligros, juntar peces y llegar a la salida.

## Publico objetivo

- Infancias a partir de los 5 anios
- Sesiones cortas
- Dificultad accesible
- Feedback visual muy claro
- Controles simples y consistentes

## Fantasia central

El jugador controla a un monstruo marino simpatico que recorre escenarios submarinos, salta entre plataformas, evita obstaculos, junta peces y usa elementos del entorno para superar enemigos y avanzar.

## Alcance comprometido por el README

El juego final debe cubrir como minimo:

- Movimiento horizontal
- Salto
- Agacharse
- Escenario submarino
- Pozos, piedras, hormigas acuaticas y pulpos
- Peces coleccionables
- Algas moviles
- Peces linterna que reaccionan al jugador
- Lanzadores de burbujas para neutralizar enemigos
- Carteles de inicio y salida
- Baile al completar nivel
- Dificultad facil y normal
- Tres niveles con dificultad creciente

## Alcance minimo jugable

Se puede considerar que existe una primera version completa cuando el juego tenga:

- Menu inicial
- Seleccion de dificultad
- Tres niveles funcionales
- Peces coleccionables y meta por nivel
- Enemigos basicos funcionales
- Salida bloqueada hasta cumplir la meta
- Sistema de vidas o reinicio segun dificultad
- Pantalla final de victoria

## Principios de diseno

- Claridad primero: el jugador debe entender rapido donde esta, que recoge y que lo lastima
- Castigo moderado: el juego debe ser accesible y no frustrante
- Progresion gradual: cada nivel introduce o combina una nueva mecanica
- Feedback constante: sonido, animacion y UI deben explicar lo que pasa
- Coherencia visual: todo debe sentirse parte del mismo mundo submarino

## Lo que no deberia pasar

- Controles con precision excesiva
- Enemigos con patrones opacos
- Saltos ciegos
- UI recargada
- Escenarios confusos para un publico infantil
