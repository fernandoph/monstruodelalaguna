# El Monstruo de la Laguna
## Descripción
El Monstruo de la laguna es un juego de plataformas sencillo para niñxs a partir de los 5 años.

El objetivo es llegar al final de cada nivel sin caer en los pozos, esquivando los obstáculos y recogiendo los peces que se encuentran por el camino.


## Los requerimientos de Juli

- El monstruo puede saltar y agacharse

- El monstruo puede moverse a la derecha y a la izquierda

- El juego transcurre debajo del mar, cerca de la fosa de las marianas y el monstruo debe recorrer un camino lleno de obstáculos, como pozos, hormigas acuáticas, pulpos y piedras. 

- El monstruo debe recoger los peces que se encuentran por el camino, para poder pasar al siguiente nivel.

- Hay algas que se mueven y que pueden ser usadas como plataformas para llegar a lugares más altos.

- Los pulpos deben mover los tentáculos como para atrapar al monstruo, pero si el monstruo se mueve rápido, puede esquivarlos.

- También hay peces linterna que iluminan el camino, pero que se apagan si el monstruo se acerca demasiado.

- El monstruo puede encontrar unos lanzadores de burbujas que puede usar para atrapar a los pulpos o a las hormigas, haciendo que suban y desaparezcan.

- Es importante que haya carteles indicativos de salida y llegada

- El monstruo hace un baile cada vez que termina el nivel

- De acuerdo a la dificultad seleccionada:
    - Fácil:  El monstruo no pierde vidas, solo se reinicia el nivel
    - Normal: El monstruo pierde una vida si cae en un pozo o si lo atrapa un pulpo o una hormiga y se reinicia el nivel.

## Controles
- **Flechas de dirección**: Mover al personaje
- **Espacio**: Saltar
- **R**: Reiniciar nivel
- **P**: Pausar juego

## Niveles
El juego cuenta con 3 niveles, cada uno con una dificultad mayor que el anterior.
